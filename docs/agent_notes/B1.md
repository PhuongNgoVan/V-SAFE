```bash
git lfs install
git lfs track "models/asr/**/*.bin"
git add .gitattributes
```

Trong CI/CD: chạy `bash scripts/convert_phowhisper.sh` trước khi test.

## 7. Singleton & Thread-Safety

`WhisperModel` được nạp **một lần** nhờ `threading.Lock` + double-checked locking:

```python
class _ASRState:
    def load(self):
        if self._loaded: return          # fast path (không lock)
        with self._lock:
            if self._loaded: return      # double-check
            self._do_load()
            self._loaded = True
```

Phù hợp với Gunicorn multi-thread và FastAPI async.
